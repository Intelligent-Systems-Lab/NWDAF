# NWDAF

Network Data Analytics Function based on 3GPP TS 29.520.

Requires Go 1.26.2. Linting requires golangci-lint v2.11.4.

## Build

```bash
make build
```

## Run

```bash
make run CONFIG=/path/to/nwdafcfg.yaml
```

## Test

```bash
make test
```

## Lint

```bash
make lint
```
